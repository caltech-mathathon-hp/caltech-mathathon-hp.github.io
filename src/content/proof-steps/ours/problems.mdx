### The idea

The puzzle is the one of the original proof. Bin packing asks whether items with given sizes can be split into $K$ bins so that each bin holds exactly $B$. An item of size 6 will become a rod of 6 H's, lying on 6 consecutive nodes of one edge of the cube, and a bin a gap of $B$ nodes on that edge.

The string grows with the sizes themselves, not with their digits. This is allowed because bin packing stays hard when every number is written in tally marks, as $6=111111$ ([2 Why bin packing](../original-proof/#step-bl-problems) of the original proof). We also keep every size even. Doubling every size and $B$ changes nothing about which items fit together, and even rods let us choose the side of their first and last P freely when we build a fold ([12 Placing a piece](#step-ours-placements)).

The original string needs at least $2B^{1/3}$ strips, so that a padding fills more than half of one. The one-edge string has no such condition: any instance with even sizes will do.

### Statement

A **packing** splits the items into $K$ groups whose sizes each add up to exactly $B$. Deciding whether a packing exists stays NP-complete when every size is even and every number is written in tally marks.

### Exact statement

A **fold** of an HP string places its letters on distinct nodes of the cubic lattice $\mathbb Z^3$, with consecutive letters on neighbouring nodes. An **H–H pair** is two H's on neighbouring nodes, consecutive in the string or not; a **contact** is an H–H pair that is not consecutive.

- **Folding.** Given an HP string and a number $m$, does the string have a fold with at least $m$ H–H pairs?
- **Bin packing.** Given a set $U$ of items with even sizes $s(u)>0$, a number of bins $K$ and a bin size $B$, with all sizes adding up to $KB$, can $U$ be split into $K$ groups $U_1,\dots,U_K$ whose sizes each add up to exactly $B$?

Bin packing in this form is NP-complete even when every number is written in unary. It stays so when we ask for $K\ge2$, and then $B\ge2$.

### Uses

No earlier card. The NP-completeness is proved in [2 Why bin packing](../original-proof/#step-bl-problems) of the original proof.

### Proof

1. **Hardness in unary.** [2 Why bin packing](../original-proof/#step-bl-problems) of the original proof doubles the numbers of a 3-PARTITION instance and gets an instance of this problem with the same answer.
2. **One bin.** If $K=1$, all the items form one group of size $B$, so the answer is yes. The reduction can answer such instances with a fixed string that has a perfect fold, such as <Seq s="H" />. So we may assume $K\ge2$.
3. **What the construction uses.** From here on we use only this: $K\ge2$, every size and $B$ are even and positive, and the sizes add up to $KB$. In particular $B\ge2$.

### Our note

Our notes reduce from 3-PARTITION with every number doubled, which is the instance that the original board builds in its card 2. The argument uses only even sizes, so we state it for the same bin packing as the original board, and the two boards share their first step.
